Why might a response fail, and what helps?

Every message you send gets resent along with the entire conversation so far — including the agent's own past replies, which tend to be detailed by design. As a conversation grows, so does the size of every subsequent request, and eventually a long-running conversation can exceed what a single request is allowed to use.

Separately, a single complex question — especially one asking the agent to reason across multiple data sources at once (cost, security, and Advisor recommendations together) — can take longer to generate than a fixed platform timeout allows. When this happens, the answer may still finish generating on the server, just too late to reach you.

What helps: start a new conversation (the button above) once you've gotten what you needed, rather than letting one run indefinitely. Asking for something specific — a single figure, one recommendation — usually gets a shorter, faster reply than an open-ended request for a full analysis, which helps with both failure modes at once. If a response times out, simply asking again often works.
